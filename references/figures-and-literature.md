# 图表、表格与文献证据

按本次任务选择相关部分，不要求每套PPT都做数据分析或文献解读。

## 图表的丰富来自问题

先说清主图回答什么，再选择辅助分图。

| 主要问题 | 主图候选 | 有用的辅助分图 |
|---|---|---|
| 变化过程是否一致 | 完整时间序列 | 分期增长矩阵、端点规模或指数对比 |
| 绝对量与相对变化是否一致 | 哑铃图、配对点图 | 累计增幅、分期变化 |
| 两种变化是否匹配 | 有明确基准的散点图 | 同对象的速率配对、差值分解 |
| 典型对象为什么不同 | 相同基期和尺度的联合轨迹 | 核心端点表、同指标变化对比 |
| 分组或阶段是否有差异 | 分组点图、分期比较 | 组内分布、样本数量、时期差值 |
| 方法究竟怎么算 | 有标注的关系图 | 真实算例表、输入输出、基准到观测的差值 |

复合图内尽量使用互补的信息形式。重复展示相同关系应有解释或核查作用。复杂度由数据和问题决定，不强行加回归、非线性曲线或更多变量。

## 数值与视觉编码

- 核对对象、时间、单位、空间范围等口径。比值的分子分母属于同一对象和范围。
- 保留有单位的坐标、清楚的比较基准、必要图例或直接标注。
- 等速、等比例等参考线只在坐标尺度一致或几何含义明确时使用，必要时设定相同轴尺度。
- 正负值以零点为基准。发散色标范围对称并标明；多个图使用不同范围时，不能直接比较色深。
- 线条较多时直接标注并使用引线，只移动标签，不挪动数据点躲避重叠。
- 保留小幅变化的符号与必要精度，避免将有意义的小负值显示为“−0.0”。显示0.0时说明四舍五入的含义。
- 差值、比率、合计用未取整数据计算。展示末位不相减或不相加时解释舍入，不改原始值凑齐。
- 不把关联、恒等式、横截面差异或概念曲线说成因果规律或发展时间轨迹。

## 生成与嵌入

- 数据图使用可复现的分析绘图工具，保留真实输入、计算过程与导出脚本。
- Python主图按实际放映尺寸提供约300dpi以上的等效像素，复杂细图可用400dpi，同时保留SVG。清晰度以最终PPT渲染为准。
- 检查像素尺寸、缩放与最终嵌入版本，注意自动降采样。DPI元数据本身不能证明细字可读。
- 图表与页内主要文字分层交付。标题、论点框、来源保持PPT文本，图片图表提供代码或矢量文件便于更新。
- 需要在PPT内改数据或表格单元格时，选择原生数据对象。准确区分图片、可编辑文字、矢量形状与数据绑定图表。
- 绘图区不用大面积网格、复杂外框、3D、阴影或默认软件配色。绘图区的克制与整页的紧凑可以同时成立。

## 文献详解讲研究脉络

重点文献围绕以下关系组织一页：

**问题与缺口 → 数据与对象 → 方法怎样连接变量 → 原图证据 → 结论与当前研究的联系。**

这是讲述逻辑，不要求画成五个同等大小的框。主图承担证据，图外说明框承担设计、发现和借鉴边界。

- 组合原文内部多幅图或分图，优先展示支撑核心论点的证据，不只是论文首页截图或题录表格。
- 图旁或页脚标明作者、年份、图号，完整题录与地址列入参考文献或来源文件。
- 原文图保留原始颜色、坐标、图例、样本与时期定义，不为统一视觉偷偷重画或改色。
- 裁切仅去掉无关边缘或选择分图，保留必要的轴、图例、组别和年份，记录范围。
- 改绘或据原表重绘的图标明“据原文数据重绘”。不冒充原图，也不将原文结果冒充自己计算。
- 如实交代摘要、全文、公开图件的获取范围。未取得全文时依据可核实材料，不补造指标、权重、模型或发现。
- 细节密集时，正文用关键原图组合，附录放大整图或分图，随交付保留可获取的高清原件。

## 图与论点共同复核

每一句发现都应回到具体图、表或数据。文献与本次结果不一致时，正面讨论样本、时段、范围或模型差别，不改图迎合文献或预设假设。

图文足够详细，当前页仍只服务一个核心问题。完整参数、逐条方法与长解释转入讲稿、附录或数据文件。
